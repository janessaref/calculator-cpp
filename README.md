## Description

A command-line calculator written in C++. Functionality works like a real calculator by keeping the running total so that it builds on the previous calculated result until you reset the calculator. 

This application was a final project for COMSC-165 class at Diablo Valley College. We were given th freely choose our own project for the final, and I built this calculator from scratch.
